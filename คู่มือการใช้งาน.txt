================================================================
  คู่มือการใช้งาน Stock Lookup Bot (หุ้นไทย SET)
================================================================

── เริ่มต้นใช้งาน ──────────────────────────────────────────────

  1. ดับเบิลคลิกไฟล์  "เริ่ม Bot.bat"  บนเดสก์ท็อป
  2. รอจนเห็นข้อความ  "Bot กำลังทำงาน..."
  3. เปิด Telegram แล้วค้นหาบอทของคุณ
  4. พิมพ์ชื่อหุ้นได้เลย

  หมายเหตุ: อย่าปิดหน้าต่าง Command Prompt ขณะใช้งาน

── คำสั่งที่ใช้ได้ ─────────────────────────────────────────────

  /start    — แสดงข้อความต้อนรับและวิธีใช้เบื้องต้น
  /help     — แสดงคำอธิบายการใช้งาน

  คำสั่งภาษาไทยทุกตัวพิมพ์เป็นอังกฤษแทนได้ (ตัวเล็ก-ใหญ่ไม่สำคัญ):
    สแกน = scan          ข่าวงบ = news        สรุปงบ = digest
    สถิติ = stats         งบ = earn            ลิสต์ = list
    ติดตาม = watch        เลิกติดตาม = unwatch  ยืนยัน = confirm
    พอร์ต = port          ไม้ = size            เทรด = trades
    ซื้อ = buy            ขาย = sell            ปฏิทิน = calendar
    เงา = shadow          วิเคราะห์ = ta        คำอธิบายงบ = mda

── ปุ่มเมนู "/" (ไม่ต้องจำคำสั่ง) ──────────────────────────────

  กดปุ่มเมนู ☰ ข้างช่องพิมพ์ (หรือพิมพ์ / เฉยๆ) จะเห็นทุกคำสั่ง
  พร้อมคำอธิบายสั้นๆ เลือกกดได้เลย เช่น
    /scan          — สแกนทั้งกระดานเดี๋ยวนี้
    /list          — ดูลิสต์หุ้นที่ติดตาม
    /watch AOT     — ติดตามหุ้น (พิมพ์ ticker ต่อท้าย)
    /price AOT     — ดูหุ้นรายตัว (หรือพิมพ์ ticker ตรงๆ แบบเดิมก็ได้)

  คำสั่ง slash ทำงานเหมือนคำสั่งพิมพ์ทุกอย่าง — เป็นแค่ทางเข้า
  อีกทางหนึ่ง คำสั่งพิมพ์ไทย/อังกฤษแบบเดิมยังใช้ได้ตามปกติ
  (เมนูลงทะเบียนอัตโนมัติตอนเปิดบอทครั้งแรก ถ้ายังไม่ขึ้นให้ปิด-เปิด
  แชทกับบอทใหม่ หรือรอสักครู่)

── วิธีดูราคาหุ้น ──────────────────────────────────────────────

  พิมพ์ ticker หุ้นได้เลย ไม่ต้องใส่ .BK

  ตัวอย่าง (ทีละตัว):
    AOT
    PTT
    CPALL

  ตัวอย่าง (หลายตัวพร้อมกัน สูงสุด 10 ตัว):
    AOT PTT CPALL KBANK SCB GULF ADVANC BDMS CPN TRUE

  เคล็ดลับ: ถามหุ้นตัวเดิมซ้ำภายใน 3 นาที บอทจะตอบทันที
  (ใช้ข้อมูลเดิม ไม่ดึงใหม่ เพื่อกันโดน Yahoo จำกัดการเรียก)

  หุ้นต่างประเทศ ใส่ ticker ตรงๆ:
    AAPL
    TSLA

── ข้อมูลที่แสดงผล ─────────────────────────────────────────────

  ราคาล่าสุด + % เปลี่ยนแปลงวันนี้

  ⚡ ปฏิกิริยาราคาวันนี้ (สำหรับดูการตอบสนองหลังประกาศงบ)
    Gap เปิดวันนี้        — ราคาเปิดกระโดดจากปิดเมื่อวานกี่ %
    เปิด → ล่าสุด         — วิ่งต่อหรือโดนขายหลังเปิด
    เปลี่ยน 5 วัน / 1 เดือน — momentum ระยะสั้น
    วอลุ่มวันนี้           — เทียบค่าเฉลี่ย 20 วัน
                             ⚡ = 1.5 เท่าขึ้นไป
                             🔥 = 2 เท่าขึ้นไป
                             🔥🔥 = 3 เท่าขึ้นไป (ผิดปกติมาก)

  🗓 วันประกาศงบ (ดึงจาก Yahoo อัตโนมัติ วันละครั้ง)
    งบล่าสุด     — ออกเมื่อไหร่ กี่วันก่อน
                   + ราคาวิ่งไปแล้วกี่ % ตั้งแต่งบออก
    วันตอบรับงบ  — วันที่ตลาดตอบรับงบ ราคาปิด +/- กี่ %
                   วอลุ่มพุ่งกี่เท่า (ใช้ดูว่างบรอบนี้
                   "ตลาดชอบ" แค่ไหน)
    งบรอบถัดไป   — อีกกี่วันจะถึงรอบประกาศครั้งหน้า

  High / Low 5 วันล่าสุด    + % ห่างจากราคาปัจจุบัน
  High / Low 3 เดือน         + % ห่างจากราคาปัจจุบัน
  52w High / Low              + % ห่างจากราคาปัจจุบัน

── คำสั่ง "งบ" (จัดการวันประกาศงบ) ────────────────────────────

  งบ AOT                — ดูวันงบล่าสุด/รอบถัดไปของ AOT
  งบ AOT 13/11/2569     — บันทึกวันงบเอง (กรณี Yahoo ไม่มี
                           หรือบริษัทเลื่อนวันประกาศ)

  ใส่ปีเป็น พ.ศ. (2569) หรือ ค.ศ. (2026) ก็ได้
  ไม่ใส่ปี เช่น "งบ AOT 13/11" = ปีปัจจุบัน

── คำสั่ง "ปฏิทิน" (ใครงบออกใน 14 วันข้างหน้า) ─────────────────

  ปฏิทิน               — หุ้นที่รู้วันงบภายใน 14 วันข้างหน้า
                          เรียงตามวัน ⭐ = อยู่ในลิสต์ติดตาม

  เติมช่องว่างของเตือนเช้า 08:45 ที่เห็นแค่ "วันนี้/พรุ่งนี้" —
  ปฏิทินให้เห็นล่วงหน้าทั้งสัปดาห์ ไว้วางแผนก่อนฤดูงบ

  บอทส่งเองสัปดาห์ละครั้ง (อาทิตย์ 19:00 — คอมปิดวันอาทิตย์
  ก็ส่งชดเชยครั้งแรกที่บอทเปิดในสัปดาห์นั้น) ไม่รู้วันงบของ
  ตัวไหนเลย = ไม่ส่ง

  ข้อจำกัด: คลังวันงบมีเฉพาะตัวที่บอทเคยเห็น (จากข่าว SET /
  เคยกดดูหุ้น / บันทึกเองด้วยคำสั่ง งบ) ไม่ใช่ปฏิทินทั้งตลาด

── คำสั่งติดตามหุ้นหลังงบ (watchlist) ──────────────────────────

  ติดตาม AOT            — เพิ่ม AOT เข้าลิสต์ติดตาม
  ติดตาม AOT PTT CPALL  — เพิ่มหลายตัวพร้อมกัน
  ลิสต์                 — สรุปทุกตัวในลิสต์ จัดอันดับตาม
                           แรงตอบรับวันงบ พร้อม % ตั้งแต่งบออก
                           และ % วันนี้
  เลิกติดตาม AOT        — เอาออกจากลิสต์
  เลิกติดตาม AOT PTT    — เอาออกหลายตัวพร้อมกัน

  ทางลัด: ใต้ผลสแกน / สรุปงบ / ยืนยัน มีปุ่ม 3 ปุ่มต่อหุ้น
    ➕ AOT   — เข้าลิสต์ทันที ไม่ต้องพิมพ์
    📐 AOT   — ข้อมูล PHASE 0 สำหรับ Gem เทคนิค (ดูหัวข้อ "วิเคราะห์")
    📅 AOT   — เปิดหน้างบของหุ้นที่ Earnings Radar
  ใต้ "ลิสต์" ก็มีปุ่ม 📐 ของทุกตัวในลิสต์ (15 ตัวแรก) ต่อจากปุ่ม 🗑

  สุขอนามัยลิสต์: เปิด "ลิสต์" แล้วตัวไหนหมดสภาพ บอทติดป้าย 🗑
  พร้อมเหตุผล และมีปุ่มกดเอาออกใต้ข้อความ (กันลิสต์บวมจนบัง
  ตัวที่ยังมีสัญญาณ):
    • โดน ⛔ หลุด Low ก่อนงบไปแล้ว — ตามกติกาต้องออก
    • งบผ่านมาเกิน 60 วัน — สัญญาณหลังงบหมดอายุ
    • ไม่รู้วันงบ — บอทเฝ้าสัญญาณให้ไม่ได้
  ยกเว้นตัวที่งบรอบใหม่จะออกภายใน 14 วัน (ติดตามรองบอยู่ —
  ไม่ชวนลบ)

── คำสั่ง "วิเคราะห์" (ข้อมูล PHASE 0 สำหรับ Gem เทคนิค) ─────────

  สแกนเจอหุ้นตอบรับงบดีแล้ว ขั้นถัดไปคือเอาไปวิเคราะห์เทคนิคต่อ
  ใน Gem เทคนิค (Gemini) — Gem มี prompt วิเคราะห์อยู่แล้ว แต่ไม่รู้
  ตัวเลขของหุ้น (ราคา/SMA/RSI/MACD/ATR/RS/วันงบ) จึงจะถามกลับ
  ทีละข้อ ก.1-ค.10 ("PHASE 0") — คำสั่งนี้ตอบ PHASE 0 ให้ครบ
  ล่วงหน้าจากตัวเลขของระบบ dashboard ตัวเดียวกับปุ่ม 📐 บนเว็บ

  วิเคราะห์ AOT   — บอทตอบข้อมูล PHASE 0 ของ AOT เป็นบล็อกกดคัดลอกได้
                    พร้อมปุ่ม "📐 เปิด Gem เทคนิค"
  ta AOT          — แบบเดียวกัน (อังกฤษ)

  ขั้นตอนใช้งาน (ทำจากมือถือได้ ไม่ต้องเปิดคอม/เปิด dashboard):
    1. กดปุ่ม 📐 ใต้ผลสแกน (หรือพิมพ์ วิเคราะห์ XXX)
    2. กดค้างที่บล็อกข้อความ → คัดลอก
    3. กดปุ่ม "📐 เปิด Gem เทคนิค"
    4. วางข้อความในแชท Gem + แนบรูปกราฟ Weekly และ Daily
    5. Gem ข้าม PHASE 0 ไปวิเคราะห์เลย ไม่ถามกลับ

  ในบล็อกยังมี 2 บรรทัดให้แก้เองก่อนส่ง (เหมือนบนเว็บ):
    ค.9 ขนาดพอร์ต: [กรอกเอง]
    ค.10 สถานะ: [มีของอยู่แล้ว / กำลังหาจุดเข้า]

  ที่มาของตัวเลข: ระบบ dashboard (Trading_Dashboard) ข้อมูลปิดตลาด
  ล่าสุด — บอทอ่านจากโฟลเดอร์ในเครื่องก่อน (DASHBOARD_SITE_DIR)
  ถ้าไม่มีหรือเก่ากว่า 5 วัน จะอ่านจากเว็บ dashboard แทน (DASHBOARD_URL)
  ข้อมูลเก่าเกิน 5 วันบอทยังส่งให้ แต่ขึ้น ⚠️ บอกอายุข้อมูล
  บรรทัด ข.8 วันประกาศงบ ใช้คลังวันงบของบอทเอง (คำสั่ง งบ / ข่าว SET)
  ค่าไหนไม่มีจะเขียน "ไม่มีข้อมูล" — บอทไม่แต่งตัวเลขเอง

  หุ้นที่ไม่อยู่ในระบบ dashboard (นอก universe ~880 ตัว) บอทจะบอกว่า
  ไม่มี — ต้องหาข้อมูล PHASE 0 เองแบบเดิม

  ตั้งค่าใน .env: DASHBOARD_SITE_DIR, DASHBOARD_URL, GEM_TA_URL
  (ลิงก์ Gem ของคุณเอง — ถ้าไม่ตั้ง ปุ่มจะเปิดหน้ารายการ Gems ให้เลือก)
  ดูตัวอย่างใน .env.example

  คำอธิบายงบ AOT  — ปุ่มลิงก์ไปหน้างบ/คำอธิบายผลประกอบการของ AOT
  mda AOT           ที่ Earnings Radar (earningsradar.pages.dev)
                    แค่ประกอบลิงก์ ไม่ได้เช็คว่ามีหน้านั้นจริง

── คำนวณขนาดไม้ (เสี่ยง 1% ของพอร์ตต่อไม้) ─────────────────────

  ตามกติกาท้าย workflow: ขนาด position ต่อตัวสำคัญกว่าการเลือก
  ตัวถูก — บอทคำนวณให้แทนการกดเครื่องคิดเลข (และแทนอารมณ์)

  พอร์ต 500000        — ตั้งขนาดพอร์ตครั้งเดียว บอทจำถาวร
                         (แยกของใครของมัน ไม่ปนกับเพื่อนที่ใช้บอทร่วม)
  พอร์ต               — ดูค่าที่ตั้งไว้
  ไม้ AOT             — ควรซื้อกี่หุ้น ถ้าเข้าราคาตอนนี้
  ไม้ AOT 64.50       — ระบุราคาเข้าเอง (วางแผนล่วงหน้า)

  สูตร: เงินเสี่ยง (1% ของพอร์ต) ÷ ระยะจากราคาเข้าถึงเส้น ⛔
  (Low 5 วันก่อนงบ) ปัดลงเป็น lot ละ 100 หุ้น — บอทตอบพร้อม
  มูลค่าไม้ กี่ % ของพอร์ต และถ้าหลุด ⛔ เสียกี่บาทกี่ %

  บอทเตือนเองเมื่อ: ราคาต่ำกว่าเส้น ⛔ ไปแล้ว (สัญญาณเสีย ไม่ควรเข้า)
  / ไม้ใหญ่เกิน 30% ของพอร์ต / งบออกเกิน 60 วัน (เส้น ⛔ เก่าไป)
  ต้องรู้วันงบของหุ้นตัวนั้นก่อน (เหมือนเงื่อนไขการติดตาม)

── บันทึกไม้จริง (trade journal) ───────────────────────────────

  ปิดวงจรสุดท้ายของระบบ: สถิติสแกนบอกว่า "ระบบ" แม่นแค่ไหน
  แต่บันทึกไม้จริงบอกว่า "เรา" เทรดตามระบบได้จริงหรือเปล่า

  ซื้อ AOT 32.50        — จดไม้เข้า ณ ราคานั้น
  ซื้อ AOT 32.50 300    — ใส่จำนวนหุ้นด้วย (จะได้เห็นกำไรเป็นบาท)
  ขาย AOT 35.00         — ปิดไม้ บอทสรุปทันที: % กำไร ถือกี่วัน
                           กำไรกี่บาท และกี่ R (เทียบเงินเสี่ยงถึง ⛔)
  เทรด                  — ไม้ที่เปิดอยู่ (R ปัจจุบัน ระยะถึงเส้น ⛔
                           เงียบมากี่วัน) + ผลไม้ที่ปิดแล้ว 10 ไม้ล่าสุด

  มีไม้เปิดอยู่ = บอทส่งรายงานสถานะให้เองทุกวันทำการ 17:45 น.
  (หลังสแกน 17:30) ต่อไม้: R ปัจจุบัน / เหลือกี่ % ถึงเส้น ⛔ /
  เงียบ (ไม่ทำไฮใหม่) มากี่วันทำการ — ตามกติกา workflow:
    ⚠️ เงียบเกิน 5 วันทำการ = เริ่มพิจารณาลด
    ⚠️ เหลือ ≤2% ถึงเส้น ⛔ = เตรียมทำตามเครื่อง
  ไม่มีไม้เปิด = ไม่ส่ง (เปิดคอมตอนค่ำเลย 17:45 ก็ส่งชดเชยให้)

  ตอนซื้อบอทแอบเก็บ "บริบท ณ ตอนเข้า" ให้เอง: วันงบ เส้น ⛔
  และคะแนนระบบวันนั้น — เพราะพวกนี้ย้อนหลังไม่ได้ ต้องเก็บสด
  หุ้นเปิดได้ทีละหนึ่งไม้ต่อตัว ซื้อซ้ำต้องปิดไม้เดิมก่อน

  พิมพ์ สถิติ แล้วจะเห็นส่วน "ผลไม้จริง" ต่อท้าย: ชนะกี่ %
  R เฉลี่ย และแยกตามช่วงคะแนน ณ ตอนเข้า — วางเทียบกับสถิติ
  ระบบตรงๆ ว่า execution ตามทันระบบไหม (บันทึกแยกของใครของมัน)

── แจ้งเตือนอัตโนมัติ (ต้องเปิดบอททิ้งไว้) ─────────────────────

  1) เช็คลิสต์ติดตามทุก 15 นาที ช่วงตลาดเปิด (10:00-17:00)
     บอทจะส่งข้อความ "เฉพาะตอนสถานะเปลี่ยน" เช่น
       🔥 ทะลุไฮ 3 เดือนก่อนงบแล้ว
       ✅ ผ่านไฮ 5 วันก่อนงบแล้ว
       📈 ทำไฮใหม่หลังงบวันนี้ (เตือนวันละครั้ง)
       ⛔ หลุด Low ก่อนงบ — สัญญาณเสีย (จุดตัดขาดทุน)
     ไม่มีอะไรเปลี่ยน = เงียบ ไม่รบกวน
     (สถานะเก็บใน watch_state.json / หุ้นที่เพิ่งเพิ่มเข้าลิสต์
      รอบแรกจะเก็บเป็นฐานก่อน ยังไม่เตือน)

── สรุปงบเช้า (รวบข่าวงบตั้งแต่เย็นวาน+เช้านี้เป็นข้อความเดียว) ──

  ช่วงฤดูงบ (ปลาย ก.พ. / พ.ค. / ส.ค. / พ.ย.) บริษัทแจ้งงบวันละ
  หลายสิบถึงร้อยตัว แทนที่ต้องไล่อ่านแจ้งเตือนย่อยทีละอัน
  บอทจะสรุปให้เป็นข้อความเดียวทุกเช้า จัดกลุ่ม:

    🔥 งบโตแรง — อยู่ใน universe/ลิสต์ติดตาม
    🔥 งบโตแรง — นอก universe
    📊 มีตัวเลขแต่ไม่เข้าเกณฑ์โตแรง
    📄 แจ้งงบแล้วแต่ยังอ่านตัวเลขไม่ได้ (แสดงเฉพาะชื่อ)

  เรียงลำดับในแต่ละกลุ่มตามความน่าสนใจ (พลิกเป็นกำไรก่อน
  แล้วเรียง %YoY มาก→น้อย) ให้เสร็จ = รายชื่อที่ควรเปิดดูปฏิกิริยา
  ราคาวันนี้ก่อนเพื่อน ⭐ = หุ้นอยู่ในลิสต์ติดตามอยู่แล้ว

  ใต้ข้อความมีปุ่ม ➕ ของตัวโตแรงที่ยังไม่ได้เฝ้า (สูงสุด 15 ตัว)
  กดปุ๊บเข้าลิสต์ติดตามทันที ไม่ต้องพิมพ์ "ติดตาม XXX" เอง
  (แบบเดียวกับปุ่มใต้ผลสแกน)

  ส่งอัตโนมัติทุกวันทำการ 08:55 น. — ถ้าเปิดคอมสายกว่านั้น
  (เช่น ~09:30) บอทจะส่งให้ทันทีตอนเปิดแทน (ไม่ส่งซ้ำถ้าวันนั้น
  ส่งไปแล้ว)

  เรียกดูเองได้ทุกเมื่อ (ไม่จำกัดจำนวนครั้ง ไม่ยิงเครือข่าย):
    สรุปงบ      — สรุปตั้งแต่ 09:00 ของวันทำการก่อนหน้า
                  (เช้าวันจันทร์ = ครอบศุกร์เย็น+เสาร์+อาทิตย์)
    สรุปงบ 3    — สรุปย้อนหลัง 3 วัน (ใส่ได้ 1-7)

  ไม่มีบริษัทแจ้งงบในช่วงนั้น = บอทตอบว่าไม่มีข้อมูล (ไม่เงียบหาย)

── ยืนยันรอบเช้า (ตลาดตอบรับหุ้นงบโตแรงเมื่อคืนยังไง) ──────────

  ต่อจากสรุปงบเช้า: พองบโตแรงแล้ว คำถามถัดไปของ workflow คือ
  "ตลาดเห็นด้วยไหม" — Gap เปิด + วอลุ่มเช้า คือคำตอบ
  บอทเช็คให้เองตอน 10:30 น. (ครึ่งชั่วโมงแรกหลังตลาดเปิด)
  เฉพาะหุ้นงบโตแรงตั้งแต่เย็นวาน แล้วจัดกลุ่ม:

    ✅ ตลาดยืนยัน   — วันนี้วิ่ง ≥2% พร้อมวอลุ่มหนา → ตัวเด่นของวัน
    😐 ยังไม่ชัด     — บวกแต่ไม่แรง หรือวอลุ่มยังเบา
    ❌ เปิดนิ่ง/ลบ   — ทั้งที่งบดี = ตลาดรู้อยู่แล้วหรือไม่เชื่อ
                       → ตัดทิ้งตามกติกา ไม่ต้องเสียดาย

  ใต้ข้อความมีปุ่ม ➕ เฉพาะกลุ่ม ✅ ที่ยังไม่ได้เฝ้า
  วันไหนไม่มีหุ้นงบโตแรง = ไม่ส่ง (นอกฤดูงบจะเงียบเป็นปกติ)

  ถ้าเปิดคอมสายกว่า 10:30 บอทส่งให้ตอนเปิดแทน (ก่อนเที่ยงเท่านั้น
  เพราะเลยจากนั้นภาพ "ครึ่งชั่วโมงแรก" หมดความหมายแล้ว)

  เรียกดูเองได้ทุกเมื่อ: พิมพ์  ยืนยัน  (หรือ confirm)
  ตัวเลขจะเป็นข้อมูล ณ ตอนที่เรียก — ยิ่งบ่ายยิ่งเป็นภาพทั้งวัน

── คำสั่ง "สถิติ" (วัดผลย้อนหลัง) ──────────────────────────────

  พิมพ์  สถิติ  ในแชท (หรือรัน python stats.py)

  ระบบย้อนดูหุ้นที่เคยติดสแกนใน scan_log.csv แล้ววัดว่า
  ผ่านไป 5 / 10 / 20 วันทำการ ราคาไปทางไหน แยกตามช่วงคะแนน
  (⭐⭐⭐ / ⭐⭐ / ⭐ / ไม่มีดาว) — ชนะกี่ % เฉลี่ยกี่ %

  ใช้ตอบคำถามว่าเกณฑ์คะแนนแม่นจริงไหม ควรปรับน้ำหนักตรงไหน
  ยิ่งปล่อยให้สแกนสะสมข้อมูลนาน สถิติยิ่งน่าเชื่อถือ

── คำสั่ง "เงา" (ไม้เงา — ระบบเทรดกระดาษเอง) ────────────────────

  พิมพ์  เงา  ในแชท (หรือรัน python shadow.py)

  ทุกตัวที่ติดสแกนถูกจำลองเป็น "ไม้เงา" หนึ่งไม้อัตโนมัติ
  ตามกติกา workflow เป๊ะ โดยไม่ใช้เงินจริง:
    เข้า     — ราคาเปิดวันทำการถัดจากวันสแกน
               (เหมือนเห็นรายงาน 17:30 แล้วซื้อเช้าวันรุ่งขึ้น)
    ตัด      — ราคาปิดหลุดเส้น ⛔ (Low ก่อนงบ) = ออกวันนั้น
    ครบเวลา — ถือครบ 20 วันทำการ = ปิดไม้

  รายงานแยกตามช่วงคะแนน: ชนะกี่ % เฉลี่ยกี่ % กี่ R —
  ต่างจาก "สถิติ" ตรงที่วัดแบบมีจุดตัดขาดทุนจริง (ไม่ใช่ถือ
  ครบกำหนดอย่างเดียว) จึงใกล้ผลเทรดจริงที่สุด

  ใช้ตอบคำถามสำคัญ: "ระบบคะแนนยังทำงานในตลาดตอนนี้ไหม"
  ด้วยข้อมูลไปข้างหน้า (backtest ตอบได้แค่อดีต) — ช่วงนอก
  ฤดูงบคือช่วงซ้อมสะสมไม้เงา พอฤดูงบจริงจะมีหลักฐานสดว่า
  ควรเชื่อคะแนนแค่ไหน

  ไม้ที่ปิดแล้วเก็บใน shadow_log.csv (ระบบอัปเดตให้เองทุกเย็น
  หลังสแกน 17:30) และสรุปย่อโผล่ท้ายรายงาน "สถิติ" ด้วย

── Backtest ย้อนหลัง (ไม่ต้องรอเก็บข้อมูลจริง) ─────────────────

  รัน:  python backtest.py   (ใช้เวลา ~5-10 นาที)

  จำลองระบบกับงบย้อนหลัง ~2 ปีของหุ้นใน universe:
  หาหุ้นที่เข้าเกณฑ์สแกน (ตอบรับ ≥2% วอลุ่ม ≥1.5 เท่า)
  แล้ววัดผลตอบแทนจริง แยกตามช่วงคะแนน ที่สองจุดตัดสินใจ:
    จุด A เข้าเย็นวันตอบรับ (คะแนนวันแรก เพดาน 11)
    จุด B เช็คซ้ำหลัง 10 วันทำการ (คะแนนเต็ม รวมความต่อเนื่อง)

  รายละเอียดรายเหตุการณ์บันทึกลง backtest_results.csv
  ข้อจำกัด: วันงบย้อนหลังจาก Yahoo ไม่ครบทุกตัว (หุ้นเล็กมักขาด)

  แนวคิด: หุ้นที่วันงบออกปิดบวกแรง + วอลุ่มพุ่ง (🔥)
  มักไปต่อได้อีกหลายสัปดาห์ (Post-Earnings Drift)
  เก็บตัวที่ตอบรับดีเข้าลิสต์ แล้วเปิด "ลิสต์" ดูทุกวัน
  ว่าตัวไหนยังวิ่งต่อ ตัวไหนเริ่มแผ่ว

  ลิสต์เก็บในไฟล์ watchlist.json ปิดเปิดบอทไม่หาย

── สัญญาณหลังงบ (คะแนน 0-15 + ดาว) ─────────────────────────────

  หุ้นที่เพิ่งออกงบ (ภายใน 60 วัน) จะมีบล็อก "สัญญาณหลังงบ"
  ให้คะแนนตามเกณฑ์:

  วันตอบรับงบปิดบวกแรง      +2.5% = 1 คะแนน, +5% = 2 คะแนน
  วอลุ่มวันตอบรับพุ่ง        2 เท่า = 1 คะแนน, 3 เท่า = 2 คะแนน
  ผ่านไฮ 5 วันก่อนงบ        = 1 คะแนน (บันไดขั้นแรก)
  ทะลุไฮ 3 เดือนก่อนงบ      = 3 คะแนน

  ความต่อเนื่องของการปรับขึ้น (รวม 6 คะแนน — น้ำหนักมากสุด):
    ไฮใหม่ล่าสุด             วันนี้/เมื่อวาน = 2, ภายใน 5 วัน = 1
    ความถี่วันทำไฮใหม่        ≥30% ของวันหลังงบ = 1, ≥50% = 2
                             (เริ่มนับเมื่อมีข้อมูล ≥5 วันหลังงบ)
    ไฮรายสัปดาห์ยกสูงขึ้น     1 สัปดาห์ = 1, 2 สัปดาห์ติดขึ้นไป = 2

  ยังอยู่เหนือ Low ก่อนงบ    = 1 คะแนน (⛔ ถ้าหลุด = สัญญาณเสีย)

  13+ = ⭐⭐⭐   9-12 = ⭐⭐   5-8 = ⭐

  แนวคิด: คะแนนความต่อเนื่องต้อง "พิสูจน์ด้วยเวลา" —
  หุ้นที่เพิ่งออกงบวันแรกได้สูงสุด 11 (⭐⭐)
  จะขึ้น ⭐⭐⭐ ได้ต้องทะลุไฮ 3 เดือน และยังทำไฮใหม่
  ต่อเนื่องรายวัน/รายสัปดาห์จริงเท่านั้น

  หลักฐาน backtest: คะแนน 9-11 วันแรก ชนะ ~64% เฉลี่ย +0.22R
  (backtest 2014-2023, 97 ไม้) • คะแนน 0-4: เลี่ยง (ชนะ 26-46%)
  คำเตือน: ปี 2024-2026 ระบบแบน — คะแนนสูงไม่ใช่คำสัญญา
  ใช้คุมขนาดไม้ (เสี่ยง 1% ต่อไม้) เสมอ

  "Low ก่อนงบ" = ราคาต่ำสุด 5 วันทำการก่อนวันงบออก
  ใช้เป็นแนวตัดขาดทุน: หลุดเมื่อไหร่ สัญญาณถือว่าเสีย

     เร็วกว่าเพราะไม่ต้องไล่เช็คหุ้นที่ราคาพุ่งแต่ไม่เกี่ยวกับงบ

  หุ้นที่เข้าเกณฑ์แต่ละรอบไปต่อจริงกี่ตัว

── ความสดของราคา (สำคัญช่วงตลาดเปิด) ──────────────────────────

  ราคาหุ้นไทยจาก Yahoo ดีเลย์ประมาณ 15 นาที
  (ข้อจำกัดของแหล่งข้อมูลฟรี)

  บอทจำผลไว้ชั่วคราวเพื่อกันโดนจำกัดการเรียก:
    ช่วงตลาดเปิด (10:00-16:45)  จำ 60 วินาที
    นอกเวลาตลาด                 จำ 3 นาที

  บรรทัดแรกของผลลัพธ์บอกเวลาที่ดึงข้อมูลเสมอ
  เช่น "ดึง 14:32 น." = ตัวเลขชุดนี้ดึงมาตอน 14:32

  ทุกการกดดูหุ้น (ที่ดึงข้อมูลสด) ถูกบันทึกต่อท้าย
  lookup_log.csv — กดดูตัวเดิมซ้ำๆ ระหว่างวันช่วงงบออก
  = ได้ประวัติปฏิกิริยาราคาเก็บไว้วิเคราะห์ย้อนหลัง

── การปิดและเปิดบอทใหม่ ────────────────────────────────────────

  ปิดบอท:   กด Ctrl+C ในหน้าต่าง Command Prompt
             หรือปิดหน้าต่างนั้นทิ้งได้เลย
             (ปิดคอมได้เลยโดยไม่ต้องทำอะไร)

  เปิดใหม่: ดับเบิลคลิก "เริ่ม Bot.bat" ได้เลย

  ระบบดูแลตัวเอง 3 ชั้น:
  1. บอทล้มเอง (error/เน็ตหลุด) → เริ่ม Bot.bat รีสตาร์ทให้เอง
     ใน 15 วินาที (Ctrl+C ปิดปกติจะไม่รีสตาร์ท)
  2. อยากให้เปิดเองทุกครั้งที่เปิดเครื่อง → ดับเบิลคลิก
     "ติดตั้งเปิดเองตอนบูต.bat" ครั้งเดียวจบ
     (ยกเลิก: ลบไฟล์ StockLookupBot.bat ในโฟลเดอร์ Startup)
  3. heartbeat: วันทำการละครั้ง บอทส่ง "✅ บอททำงานปกติ" —
     ตอน 08:30 ถ้าเครื่องเปิดอยู่ หรือทันทีที่เปิดบอทครั้งแรก
     ของวัน เปิดเครื่องแล้วไม่เห็น ✅ = บอทไม่ได้รัน ให้ไปเปิดใหม่

  เก็บตกอัตโนมัติ: ถ้าบอทปิดไปนานเกิน ~20 ชม. พอเปิดใหม่
  ระบบจะดึงข่าวย้อนช่วงที่หายไป (สูงสุด 7 วัน) มาบันทึก
  วันงบ + ตัวเลข F45 ให้เองแล้วส่งสรุปมาบอก — ปิดบอทยาว
  สุดสัปดาห์/ไปเที่ยวได้โดยไม่เสียข้อมูล
