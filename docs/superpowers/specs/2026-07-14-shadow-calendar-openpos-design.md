# ดีไซน์: Shadow tracking + ปฏิทินงบ + รายงานไม้เปิด (2026-07-14)

อนุมัติโดยผู้ใช้ในแชท — สามฟีเจอร์เตรียมระบบก่อนฤดูงบ Q2 (~กลางสิงหาคม)

## 1. Shadow tracking — "ไม้เงา" (โมดูลใหม่ `shadow.py`)

หลักการ: replay ย้อนหลังจาก `scan_log.csv` ตามปรัชญา "คำนวณย้อนหลังได้เสมอ" —
ไม่มี job เฝ้ารายวัน ไม่มี state ที่พังตอนปิดบอทนาน

- ไม้เงา = แถวแรกต่อ (ticker, earn_date) ใน scan_log (หุ้นเดิมโผล่หลายวันนับครั้งเดียว)
- เข้า: ราคาเปิดวันทำการถัดจาก scan_date (เห็นรายงาน 17:30 → ซื้อเช้าวันรุ่งขึ้น)
- ตัด: ปิดหลุด pre_earn_low → ออกที่ราคาปิดวันนั้น (ตรงกับ job เฝ้าลิสต์)
- หมดเวลา: ครบ 20 วันทำการ → ปิดที่ราคาปิด (ตรง horizon backtest)
- R = (exit − entry) / (entry − stop); ข้ามไม้ที่ entry ≤ stop (ระยะเสี่ยงเป็นศูนย์/ติดลบ)
- ติดตามทุกคะแนน → รายงานแยกช่วงคะแนน (BANDS เดียวกับ stats/backtest)
- ไม้ปิดแล้ว cache ลง `shadow_log.csv` (append-only, gitignore) — เรียกซ้ำไม่ยิง Yahoo
- ทางเรียก: คำสั่ง `เงา`/`shadow` (อัปเดต + รายงานเต็ม), ต่อท้าย `สถิติ` เฉพาะสรุปจาก cache
  (ไม่ยิง Yahoo — สถิติต้องเร็ว), และหลังสแกนอัตโนมัติ 17:30 อัปเดต cache ให้เองทุกวัน

## 2. ปฏิทินงบล่วงหน้า

- คำสั่ง `ปฏิทิน`/`calendar`: หุ้นที่รู้วันงบใน 14 วันข้างหน้า จากคลังวันงบ
  (Yahoo cache + manual) เรียงตามวัน ติด ⭐ ตัวที่อยู่ใน watchlist ของ chat นั้น
- อัตโนมัติ: อาทิตย์ 19:00 + startup fallback — กันซ้ำด้วย "วันอาทิตย์ล่าสุด" (anchor)
  ใน digest_state key `calendar_last_sent`: ส่งเมื่อ anchor ปัจจุบัน ≠ ที่บันทึก
  (ส่งวันอาทิตย์แล้ว บูตวันจันทร์ไม่ส่งซ้ำ; ข้ามอาทิตย์ไป บูตวันไหนก็ส่งชดเชย)
- ไม่มีตัวไหนรู้วันงบใน 14 วัน = ไม่ส่งอัตโนมัติ (คำสั่งเรียกเองตอบ "ไม่มี")

## 3. รายงานไม้เปิดประจำวัน

- job 17:45 จันทร์-ศุกร์ (หลังสแกน 17:30 — cache ราคายังอุ่น) เฉพาะ chat ที่มีไม้เปิด
- ต่อไม้: R ปัจจุบัน · % เหนือเส้น ⛔ · เงียบมากี่วันทำการ (นับจากวันปิดไฮล่าสุดหลังเข้า)
  · ⚠️ ถ้าเงียบ ≥5 วัน หรือใกล้ ⛔ ≤2%
- คำสั่ง `เทรด` เดิม: ไม้ที่ยังเปิดโชว์ข้อมูลชุดเดียวกันนี้
